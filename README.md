# Kirellos George | Portfolio

Welcome to my personal portfolio website! This project is a curated showcase of my skills, projects, and creative journey. It is designed with a unique visual style that blends retro desktop folder aesthetics with modern, premium UI/UX design.

🌐 **Live Demo**: [kirellosgeorge2010-pixel.github.io/Portfolio-Kirellos](https://kirellosgeorge2010-pixel.github.io/Portfolio-Kirellos/)

---

## ✨ Features

- **iOS Liquidity & Spring Physics**: Interactive elements (navigation links, folders, project cards, buttons) respond with organic, bouncy scaling transitions (`cubic-bezier` easing) and snap active states for a high-end, tactile application feel.
- **Retro Folder Aesthetic**: A creative "desktop folders" hero screen that floatingly showcases main focus areas: Graphic Design, Video Editing, and Programming.
- **Responsive Layout**: Fluid layouts and typography (`clamp()` scaling) that look exceptional on screens ranging from small smartphones (iPhone SE) to wide desktop monitors. Folders dynamically align into a clean wrapping grid on mobile viewports.
- **Interactive Call Me Button**: A floating action button (FAB) with an iOS-style pulsing dot that triggers a custom bottom Action Sheet modal. Users can easily choose to chat on WhatsApp or send an email, complete with an elastic mobile swipe-to-dismiss gesture.
- **Functional Contact Form**: Built-in email form handling using Formspree.

---

## 🛠️ Technologies Used

- **HTML5**: Semantic web structure.
- **CSS3 (Vanilla)**: Flexbox, Grid, custom bezier animations, backdrop glassmorphism blurs, and viewport-relative scaling.
- **JavaScript (Vanilla)**: Event listeners, Intersection Observer for viewport triggers, smooth scrolling, and custom swipe gesture recognition.
- **Formspree**: Contact form endpoint services.
- **Google Fonts**: Outfit / DM Sans for clean typography & Playfair Display for creative titles.

## 🚀 How to Run Locally

Since this is built with lightweight vanilla web technologies, there are no package installations required!

1. Clone this repository:
   ```bash
   git clone https://github.com/kirellosgeorge2010-pixel/Portfolio-Kirellos.git
   ```
2. Navigate to the folder:
   ```bash
   cd Portfolio-Kirellos
   ```
3. Open `index.html` in your favorite web browser (or run a local development server like VS Code Live Server).
